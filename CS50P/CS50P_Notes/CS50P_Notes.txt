→ Python does not have unary increment or decrement operators. i-- or i++ is not possible in Python.

→ if you want to print a thing multiple times
    print("hello\n" * 5, end="")

→ python does not have "do-while" loop, so when you want a user input that matches a certain expectation then infinite while loop with break is used.
    while True:
        n = int(input("n: "))
        if (n > 1):
            break
    
    for _ in range(n):
        print("*" * n)

* Week 3 : Exceptions
* -------------------

! SyntaxError : 
    → errors made by programmers
! ValueError : 
    → incorrect output - if the system wants an int input, but user types a string
! NameError : 
    → calling a variable before its existence
! IndexError:
    → index out of range


^ try-except-else:
else block will execute when the catch block will not execute, meaning everthing is fine inside try block, there's no exception.
   
example:
    while True:
        try:
            x = int(input("what's x: "))
        except ValueError:
            pass #to silently ignore the catch block, if the error occured, don't do anything
        else:
            print(f"x is {x}")
            break

→ It's better to separate main logic from if-else code or exception handling code. 

→ If you have defined your own module, and wrote all the code in 'main()' function then when you call that module in another python file then main() function will execute first then that specific functionality.
for example,
    &base.py file,
    def main():
        hello("World!") 

    def hello(name):
        print(f"Hello, {name}!")
    
    main()

    &say.py file,
    from base import Hello

    name = input("Name: ")
    hello(name)

    &output:
    Hello, World!
    Hello, Rinkal!

    → to avoid this, write following line of code in module file:
        if __name__ == "__main__":
            main()

        now, main() is only called when you run the program from terminal, if you call a module, then main()    function will not be called.
